# کتابخانه آنلاین حرکات

## تصمیم محصول

- برای هر حرکت فقط یک ویدئوی آموزشی کامل نگهداری می‌شود.
- تصویر شروع و پایان اختیاری است و نبودن آن مانع انتشار حرکت نیست.
- هیچ ویدئویی به‌صورت خودکار دانلود نمی‌شود.
- مربی و شاگرد هر دو می‌توانند هر ویدئو را به‌صورت دستی دانلود و حذف کنند.
- داده‌های اصلی برنامه در SQLite باقی می‌مانند و کتابخانه آنلاین فقط منبع به‌روزرسانی است.

## معماری رایگان نسخه اول

- Supabase Free: اطلاعات حرکات، حساب‌ها و مجوزهای دسترسی.
- Cloudflare R2 Free: فایل‌های MP4 و تصاویر اختیاری.
- یک فایل Manifest عمومی و نسخه‌بندی‌شده، فهرست حرکات منتشرشده را به اپ می‌دهد.

آدرس عمومی فعلی محیط توسعه:

```text

```

Manifest پیش‌فرض برنامه:

برای محیط staging یا production می‌توان آدرس پیش‌فرض را هنگام Build بازنویسی کرد:

پلن رایگان برای شروع و آزمایش بازار مناسب است، نه یک تضمین دائمی برای هر تعداد کاربر. مصرف فضای R2، تعداد درخواست‌ها و حجم دیتابیس باید پایش شود تا پیش از رسیدن به سقف، فشرده‌سازی یا ارتقای پلن انجام شود.

## استاندارد فایل ویدئو

- MP4 با H.264 و صدای AAC در صورت وجود توضیح صوتی.
- HTTPS اجباری در محیط تولید.
- هر فایل ترجیحاً کمتر از 50 مگابایت.
- نام فایل شامل شناسه پایدار حرکت و نسخه رسانه باشد.
- ویدئو به‌صورت کامل نمایش داده می‌شود؛ نسخه کوتاه یا متوسط نگهداری نمی‌شود.
- تصویرها WebP و اختیاری هستند.

## رفتار آفلاین

1. کاربر ویدئو را آنلاین پخش می‌کند یا «دانلود برای آفلاین» را می‌زند.
2. فایل ابتدا با پسوند `.part` دریافت می‌شود.
3. فقط پس از کامل‌شدن دانلود به مسیر نهایی منتقل می‌شود.
4. نسخه URL و `media_version` در SQLite ذخیره می‌شود.
5. در صورت انتشار نسخه جدید، دانلود قدیمی معتبر تلقی نمی‌شود.
6. حذف دانلود فقط فایل رسانه را پاک می‌کند و حرکت از کتابخانه حذف نمی‌شود.

## تقویم

- نمایش و انتخاب تاریخ برای کاربر جلالی است.
- مقدار ذخیره‌شده همچنان UTC/Gregorian باقی می‌ماند.
- این جداسازی برای Sync، مرتب‌سازی و تبادل بین دستگاه‌ها ضروری است.
