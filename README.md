# Coach App

اپلیکیشن فارسی و آفلاین مربی ورزشی، ساخته‌شده با Flutter.

## وضعیت فعلی

نسخه `0.1.0` پایه فنی محصول را ایجاد می‌کند:

- معماری Feature-first و قابل توسعه
- رابط فارسی و راست‌به‌چپ
- دیتابیس محلی SQLite با نسخه‌بندی Schema
- ماژول مدیریت شاگردان
- ثبت، ویرایش و بایگانی نرم شاگرد
- لایه Repository مستقل از UI
- تست‌های پایه مدل دامنه
- CI برای Analyze، Test و ساخت APK

## اجرای پروژه

```bash
flutter pub get
flutter create . --platforms=android
flutter run
```

در FlutLab، ریپو را Import کنید. اگر پوشه Android به‌صورت خودکار ایجاد نشد، دستور `flutter create . --platforms=android` را اجرا کنید.

## اصل‌های پروژه

1. داده محلی منبع اصلی نمایش است.
2. برنامه منتشرشده در آینده Immutable و نسخه‌دار خواهد بود.
3. اپ مربی و ورزشکار قرارداد تبادل داده مشترک خواهند داشت.
4. UI به SQLite وابستگی مستقیم ندارد.
5. حذف داده به‌صورت Soft Delete انجام می‌شود.
6. هر تغییر Schema دارای Migration خواهد بود.

جزئیات در `docs/ARCHITECTURE.md` ثبت شده است.
